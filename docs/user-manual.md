# DeepLux Vision 软件操作手册

本文面向使用 DeepLux Vision 创建、调试和运行机器视觉流程的操作员与应用工程师。内容依据当前仓库的 Qt 界面、执行引擎、69 个插件元数据及关键算法实现整理。

> 内容核对日期：2026-11-03（DeepLux_codex 工作区快照，不代表产品发布版本）。默认参数只能作为调试起点，不能替代现场样本标定、量具比对、相机/PLC 联调和节拍验收。相机 SDK、真实 PLC、SAM 权重及 GPU 推理效果需在目标设备上验证。

- [插件手册](plugins.md)：全部 69 个插件的用途、接入方式、关键配置、结果和失败条件。
- [架构说明](architecture.md)：工程、执行引擎、插件、Agent 与 SAM 的职责边界。
- [CLI 文档](cli.md)：GUI 之外的工程操作命令。

## 1. 使用前准备与安全边界

### 1.1 运行前检查

1. 启动后确认插件加载完成；左侧工具区应显示图像处理、检测识别、几何测量、逻辑、通信等分类。
2. 若插件为空或刚重新编译过插件，先执行 `cmake --build build --target sync-plugins`，再重启软件。
3. 文件流程先使用可重复的离线样本调参，再切换到相机或在线目录。
4. PLC 写入、串口发送、TCP 发送、文件覆盖和文件夹删除应先在隔离环境验证目标地址与数据格式。
5. 循环运行前必须完成一次单步和一次单次运行，确认没有路径、端口、变量、单位或超时错误。

### 1.2 工程与文件

- 工程文件扩展名为 `.dproj`，保存模块、参数、连线、布局和数据源信息。
- 图像可从相机、单个文件或文件夹读取。界面拖放支持 `png`、`jpg`、`jpeg`、`bmp`、`tif`、`tiff` 和 `ply`。
- `tif/tiff` 在主界面拖入时按 3D/高度数据路径加载；超过 100 MB 的 TIFF 当前会以步长 2 跳采样，以降低界面阻塞风险。
- 模型权重、API Key、现场 IP、串口名和本机绝对路径属于环境配置，不应随工程公开分发。

### 1.3 参数口径

同一参数可能同时出现在右侧检查器和模块“高级配置”中：

1. 检查器字段、标签和常规范围来自插件 `metadata.json`。
2. “高级配置”适合数组、坐标、通信等专用编辑器；点“确定”前会执行参数校验。
3. 插件运行时校验是最终安全边界。若两个入口显示范围不同，以能够通过运行时校验并经样本验证的值为准。
4. 本手册给出的默认值来自插件构造代码；项目中已保存的参数会覆盖默认值。

## 3. 创建并运行第一个流程

### 3.1 新建或打开工程

- 新建：选择“文件 → 新建方案”或工具栏“新建方案”。
- 打开：选择“文件 → 打开”，载入 `.dproj`。
- 最近工程：选择“文件 → 方案列表”。
- 保存：选择“文件 → 保存”；首次保存时指定 `.dproj` 路径。

窗口左上角工程面包屑会显示当前工程名；鼠标悬停可查看已保存路径。

### 3.2 导入离线图像

最省步骤的方法是把图像拖到中央主视图：

1. 软件在没有工程时自动创建工程。
2. 图像加入“数据源”页。
3. 若流程已有 `GrabImage`，软件会尝试把文件路径写入该模块。
4. 在主视图确认加载的是目标样本。

也可先添加 `GrabImage`，在检查器把“图像源”设为“自动路径”，然后选择文件或文件夹。

### 3.3 添加、排序和删除模块

1. 在左侧搜索插件中文名或插件 ID。
2. 将插件拖入“流程”页列表；软件会创建唯一实例名。
3. 在流程列表中上下拖动可调整模块顺序。
4. 选中模块后按 `Delete`，或右键选择“删除”。运行中不能删除模块，应先点“停止”。

列表顺序便于阅读；存在连线时，执行引擎会校验连接并按拓扑顺序运行，不能依赖视觉顺序掩盖错误连线。

### 3.4 在画布连接端口

1. 切换到“画布”页。
2. 从上游节点右侧输出端口拖到下游节点左侧输入端口。
3. 只有数据类型兼容、且同为数据端口或同为控制端口的连接才会建立。
4. 必需端口在画布上有标记；悬停端口可查看名称、数据类型、是否必需及是否允许多输入。

典型 2D 链路：

```text
GrabImage.image → PerProcessing.image → FindCircle.image
```

强类型结果应连接同类型端口，例如 `SamPredict.region → RegionStats.region`、点集连接到 `FitLine/FitCircle/FitEllipse.fit_points`。

### 3.5 配置参数

1. 单击流程列表或画布节点，右侧检查器切换到该实例。
2. 在“参数”页修改值。修改会标记节点为待运行，并可通过 `Ctrl+Z` / `Ctrl+Y` 撤销或重做。
3. 坐标数组、裁剪矩形、通信和标定等专用参数，从检查器右下角菜单打开“高级配置”。
4. 先缩小 ROI 或尺寸范围，再调阈值；一次只改变一类参数并记录结果。
5. 调整后重新运行，不能把旧“结果”页当作新参数结果。

### 3.6 单步、单次、循环和停止

| 控制 | 行为 | 适用场景 |
| --- | --- | --- |
| 单步 | 每次推进一个节点 | 首次搭建、定位失败节点、检查中间数据 |
| 单次运行 / 运行 | 完整执行当前流程一次 | 参数验收、离线样本测试 |
| 循环运行 / 循环 | 一轮结束后继续下一轮 | 相机或文件夹在线输入 |
| 停止 | 请求取消当前执行并结束循环 | 参数修改、异常处理、设备断开前 |

节点可在检查器中设“断点”。流程运行到该节点会暂停，此时“运行”按钮显示为“继续”。禁用的节点会跳过；逻辑控制和必需数据链路中禁用节点前，应确认下游仍有合法输入。

### 3.7 查看结果与保存

- 主视图：检查图像、点云和叠加位置是否正确。
- 检查器“结果”页：检查结果键、数值、错误信息和单节点耗时。
- 流程列表：右列显示最近一次节点耗时，底部显示总耗时。
- 运行日志：检查失败原因、设备超时和插件告警；日志页再次点击可打开日志文件。
- 工程保存只保存配置；若需保存图像或测量数据，应在流程末端添加 `SaveImage`、`SaveData` 或 `WriteText`。

## 4. 参数调优通用方法

### 4.1 推荐调优顺序

1. 固定相机位置、焦距、曝光、增益、光源和工件姿态。
2. 用正常、边界和缺陷样本分别建样本集，避免只对一张图调参。
3. 先确认输入通道、位深、坐标系和单位，再设置 ROI。
4. 先做必要的去噪或对比度处理，再调检测阈值。
5. 先限制几何范围（半径、面积、角度、长度），再调得分或梯度阈值。
6. 记录每次变更，并对全样本集统计漏检、误检、重复性和耗时。
7. 最后接入 PLC、文件写入和循环运行，完成断网、超时、空输入和停止测试。

### 4.2 阈值与方向

- 灰度/梯度阈值增大：通常减少弱边缘与噪声，也可能漏掉低对比目标。
- 匹配阈值增大：候选更严格，误匹配减少，漏匹配风险增加。
- RANSAC 距离阈值增大：更多点成为内点，抗噪更宽松，但拟合可能被离群点拉偏。
- RANSAC 迭代次数增大：找到好模型的概率提高，耗时也增加。
- 形态学核或迭代次数增大：作用范围扩大，可能连接原本分离的区域或侵蚀掉小目标。
- ROI 越小：通常越快、干扰越少，但必须覆盖工件在所有正常偏移下的位置。

### 4.3 单位与坐标

- 2D 图像几何参数通常使用像素 `px`，原点位于图像左上，X 向右、Y 向下。
- 3D/高度图是否为毫米取决于 `pixelSizeX`、`pixelSizeY` 和 `zScale`；默认值 1.0 只表示未标定比例，不能自动证明单位为毫米。
- 圆半径、面积和距离上下限应由标定件或量具建立，不应仅凭屏幕观感设置。
- 高度图的 NoData/无效值必须在预处理、平面拟合和间隙测量中保持一致；上游提供 `height_invalid_value` 时，下游优先消费该契约。

## 5. 常用 2D 算法与参数

### 5.1 图像采集 GrabImage

| 参数 | 默认值 | 范围或选项 | 说明 |
| --- | ---: | --- | --- |
| `grabSource` | `Camera` | `Camera` / `Path` / `Demo` | `Path` 会根据路径自动识别单文件或文件夹 |
| `filePath` | 空 | 图像文件或文件夹 | 支持常见 2D 格式和 TIFF |
| `folderLoop` | `true` | 布尔 | 文件夹末尾是否从头继续 |
| `exposureTime` | `10000` | ≥0，单位 µs | 仅在相机支持时生效 |
| `gain` | `1.0` | ≥0 | 增益提高也会放大噪声 |
| `grabTimeout` | `5000` | 100–60000 ms | 相机采集等待上限 |

先以文件模式复现算法，再切换相机。相机参数的实际可用范围由驱动和设备决定。

### 5.2 图像预处理 PerProcessing

算法包括 GaussianBlur、MedianBlur、BilateralFilter、Sobel、Laplacian、Canny，以及膨胀、腐蚀、开、闭、形态学梯度。

| 参数 | 默认值 | 常用范围 | 调整建议 |
| --- | ---: | --- | --- |
| `processType` | `GaussianBlur` | 上述 11 种处理 | 一次只启用一种并对比输入输出 |
| `kernelSize` | `5` | 高级配置 1–31 | 偶数会在执行时加 1 变为奇数；越大越平滑 |
| `sigmaX` | `1.5` | ≥0 | 高斯和双边滤波强度参数 |
| `iterations` | `1` | 高级配置 1–10 | 主要影响形态学操作 |

当前 Canny 的低/高阈值固定为 50/150，界面参数只调整孔径核；Canny 模式应使用 OpenCV 支持的奇数孔径 3、5 或 7。如需开放阈值，应使用专用插件或后续扩展。

### 5.3 斑点分析 Blob

Blob 先将输入转灰度并二值化，再用外轮廓计算面积、周长、质心和圆度 `4πA/P²`，最后按面积和圆度筛选。

| 参数 | 默认值 | 有效/界面范围 | 调整建议 |
| --- | ---: | --- | --- |
| `thresholdType` | `Otsu` | `Otsu` / `Fixed` / `Adaptive` | 光照稳定可固定阈值，渐变光照优先自适应 |
| `fixedThreshold` | `127` | 0–255 | 仅固定阈值模式生效 |
| `adaptiveBlockSize` | `11` | 3–51，奇数 | 大于局部噪声、但小于光照变化尺度 |
| `adaptiveC` | `2` | -50–50 | 调整局部阈值偏移 |
| `minArea` | `10` | 1–100000 px² | 排除小噪声 |
| `maxArea` | `10000` | 1–1000000 px²，且大于最小面积 | 排除背景大区域 |
| `minCircularity` | `0.5` | 0–1 | 越接近 1 越偏好圆形 |

输出包含 `blob_count`，并为最大 Blob 附加中心、面积、周长和圆度。

### 5.4 找圆、圆检测与 FindCircle

`FindCircle` 使用 OpenCV Hough Gradient 圆变换。处理前固定执行 9×9、σ=2 的高斯模糊；圆心最小间距固定为图像高度的 1/8。

| 参数 | 默认值 | 范围 | 调整建议 |
| --- | ---: | --- | --- |
| `minRadius` | `10` | 检查器 1–1000 px | 尽量贴近目标最小尺寸 |
| `maxRadius` | `500` | 检查器 1–2000 px，且大于 `minRadius` | 范围过宽会增加干扰和耗时 |
| `param1` | `50` | 检查器 1–500；高级配置 1–200 | Canny 高阈值；增大可抑制弱边缘 |
| `param2` | `30` | 1–200 | 霍夫累加器阈值；减小可增加候选 |

输出 `circle_center_x/y`、`circle_radius` 和强类型 `circle`。当前 `circle_score` 固定写为 1.0，不是可用于质量判定的置信度。

### 5.5 卡钳圆测量 MeasureCircle

模块围绕初始圆均匀发射径向卡钳，在 `[初始半径-搜索半长, 初始半径+搜索半长]` 内寻找最大灰度梯度点，再以代数最小二乘拟合圆；可按残差剔除离群点后重拟合。

| 参数 | 默认值 | 校验范围 | 调整建议 |
| --- | ---: | --- | --- |
| `initialCenterX/Y` | `320 / 240` | 0–1e6 | 初始圆必须接近真实目标 |
| `initialRadius` | `100` | 1–1e6 px | 设为目标名义半径 |
| `threshold` | `20` | 0–255 | 径向灰度梯度阈值 |
| `measureCount` | `36` | 8–360，整数 | 增大可提高覆盖密度，也增加耗时 |
| `searchLength` | `20` | 1–500 px | 覆盖正常位置和半径波动 |
| `exclusionRadius` | `0` | 0–500 px | 0 不剔除；正值为允许残差上限 |

结果包含圆心、半径、直径、圆度和有效边缘点数。纯色图、两通道图、有效点不足或退化点集会失败关闭。

### 5.6 模板匹配 Matching

`Matching` 使用灰度 `TM_CCOEFF_NORMED` 归一化相关系数，并对已命中的邻域做抑制以寻找多个目标。

| 参数 | 默认值 | 有效/界面范围 | 调整建议 |
| --- | ---: | --- | --- |
| `matchThreshold` | `0.8` | 运行校验 `(0,1]`；高级配置 0.1–1.0 | 从 0.8 起，按误检/漏检折中调整 |
| `maxMatches` | `10` | 高级配置 1–100 | 设为业务可能出现的最大数量 |

模板应由上游以 `template_qimage` 元数据提供；若未提供，当前实现会把输入图像中心、边长约为短边 1/4 的区域当作临时模板。该算法不具备旋转和尺度不变性，工件角度或尺寸变化时需重新验证。

### 5.7 直线与矩形 MeasureLine / MeasureRect

- `MeasureLine`：Canny 边缘后执行概率霍夫直线变换 `HoughLinesP`。默认最小/最大长度 20/1000 px、阈值 50、角度 0–180°；最大线段间隙固定为 10 px。
- `MeasureRect`：Canny 后提取外轮廓并筛选矩形。默认面积 100–100000 px²，Canny 阈值 50/150。

先用长度、面积和角度限制目标几何范围，再调边缘阈值。反光、断边或过度平滑会造成线段碎裂和矩形漏检。

### 5.8 点集拟合 FitLine / FitCircle / FitEllipse

| 模块 | 算法与默认参数 | 调参要点 |
| --- | --- | --- |
| `FitLine` | RANSAC；阈值 3 px；100 次。也可选最小二乘 `LS` | 离群点多用 RANSAC；干净点集可用 LS |
| `FitCircle` | RANSAC；阈值 2 px；100 次；半径 1–1000 | 先收紧半径范围，再调内点阈值 |
| `FitEllipse` | RANSAC；阈值 2；100 次；半轴 0.5–5000 | 至少 5 个有限、非退化点；迭代上限 1000 |

阈值表示点到候选几何的残差容许量。阈值过小会导致内点不足，过大会把离群点纳入。重复点、共线点、NaN/Inf 和严重病态点集会被拒绝。

### 5.9 颜色、二维码与实验性缺陷检测

- `ColorRecognition` 按目标颜色生成掩膜并做形态学清理；应先稳定照明和白平衡。
- `QRCode` 使用 OpenCV `QRCodeDetector`，当前只开放 `QR_Code`；Code 128、Code 39、EAN 等条码未开放。
- `JiErHanDefectsDet` 是基于 Canny、闭运算和轮廓的实验性候选检测，不是已验证的工业深度学习模型，不得直接作为放行结论。

## 6. 2.5D 与 3D 算法参数

### 6.1 高度图预处理 3DPreProcessing

该模块将高度图转为 `CV_32F`，支持两通道深度提取、自动 NoData 检测、高度筛选和矩形 ROI，并输出有效/过滤像素数及存活高度范围。

| 参数 | 默认值 | 校验范围 | 说明 |
| --- | ---: | --- | --- |
| `heightFilterEnabled` | `false` | 布尔 | 开启后保留上下限内高度 |
| `heightFilterMin/Max` | `0 / 65535` | -1e6–1e6，且下限≤上限 | 必须使用原始高度的实际单位 |
| `fillValue` | `0` | -1e6–1e6 | 被过滤像素的无效值；不能与存活高度碰撞 |
| `autoNoData` | `true` | 布尔 | 自动识别 TIFF 重复极值哨兵 |
| `roiCenterX/Y` | `0 / 0` | 0–1e6，整数 | ROI 中心 |
| `roiWidth/Height` | `0 / 0` | 0–1e6，整数 | 两者同为 0 表示全图；否则必须同时大于 0 |

先观察 `valid_pixel_count`、`filtered_pixel_count`、`min_height` 和 `max_height`，确认无效值没有混入，再进行拟合或间隙测量。

### 6.2 平面拟合 FitPlane

`FitPlane` 在全图或旋转矩形 ROI 内按 `pixelSizeX/Y` 和 `zScale` 建立物理坐标，以最小二乘/SVD 拟合平面，并输出法向、平面距离、平面度、偏差极值和 RMS。

默认 ROI 长短边均为 0（全图），角度 0°，`pixelSizeX=1`、`pixelSizeY=1`、`zScale=1`、`invalidValue=0`、`autoNoData=true`。像素尺寸和 Z 比例必须严格大于 0；ROI 长短边必须同时为 0 或同时为正。默认比例只适合算法联通，不代表完成物理标定。

### 6.3 截面间隙 GapMeasure3D

`GapMeasure3D` 对高度图 ROI 做行均值形成一维轮廓，可先中值/高斯平滑，再以导数峰寻找两侧拐角，输出间隙宽度、偏移后宽度、拐角水平/垂直/欧氏距离以及规格判定。

| 参数 | 默认值 | 关键范围或含义 |
| --- | ---: | --- |
| `roiCenterX/Y` | `320 / 240` | 截面中心像素 |
| `roiLength` | `100` | ≥5 px，截面长度 |
| `roiHeight` | `5` | ≥1 px，参与行均值的宽度 |
| `pixelSizeX` | `1.0` | >0，X 像素间距 |
| `zScale` | `1.0` | >0，高度比例 |
| `smoothSigma` | `1.0` | 0–100；0 关闭高斯 |
| `medianSize` | `0` | 0 关闭；否则 3–101 奇数 |
| `derivativeThreshold` | `0.05` | 导数峰阈值 |
| `edgeTrim` | `2` | 剔除轮廓两端点数 |
| `minPeakDistance` | `5` | 两峰最小像素间距 |
| `offsetMm` | `0` | 对结果施加的业务偏移 |
| `specUpperLimit` | `10` | 合格上限 |
| `measureFailValue` | `-1` | 未检出时输出值；同时检查 `gap_found=false` |

不得只用 `gap_width` 判断：业务逻辑应先检查 `gap_found`，再读取宽度和 `is_pass`。

### 6.4 点云加载与自由曲面

- `LoadPointCloud` 读取 `.ply`、`.tif`、`.tiff`；默认 TIFF 步长 1，XYZ 缩放均为 1.0。
- `FreeformSurface` 使用输入的全部点云点进行 SVD 平面拟合，计算点到拟合平面的 RMS 距离和投影凸包面积。点数少于 3 时面积与粗糙度为 0；算法不会降采样，也没有采样间隔参数。旧工程中的 `samplingInterval` 字段会被运行模块忽略。
- `PointSurfaceDistance`、`MeasureGap` 等强类型几何模块要求上游提供合法点、线或平面数据，不能仅凭同名字符串完成连接。
- `DefectDetection` 的 HymsonVision3D 算法当前未启用：`ENABLE_HYMSON3D=OFF` 时只构建不可用的框架插件；即使找到 SDK，插件 CMake 当前仍以 `AND FALSE` 禁用算法代码。Agent 或 GUI 运行会明确失败 `HymsonVision3D SDK 未启用，缺陷检测不可用`，不会产生检测结果。metadata 虽声明 `defect_point_cloud`、`has_defects`、`defect_count`，但当前不可读取为成功结果；接入 SDK、恢复算法构建并通过有效业务验收前，不得用于产品判定。启用后的参数仍需用现场点云和标注缺陷标定。

## 7. 典型流程配方

### 7.1 离线找圆

```text
GrabImage → 可选 PerProcessing → FindCircle → SaveImage / SaveData
```

1. 用一张边缘清晰的样本确定合理半径范围。
2. 单步到 `FindCircle`，先调 `param2` 直到稳定检出，再用 `param1` 排除弱边缘。
3. 用正常位置、最大偏移、最暗和最亮样本回归。
4. 质量判定使用圆心/半径及业务公差，不使用当前固定为 1.0 的 `circle_score`。

### 7.2 Blob 面积与数量检测

```text
GrabImage → PerProcessing（可选）→ Blob → DataCheck → SaveData / PLCWrite
```

先查看二值效果，再设置面积和圆度；`DataCheck` 通过后才能驱动 PLC。必须同时测试目标缺失、多个目标、粘连、断裂和光照漂移。

### 7.3 卡钳圆与拟合圆

- 图像边缘测量：`GrabImage → MeasureCircle`。
- 已有点集拟合：点集生产模块 → `FitCircle.fit_points`。

`MeasureCircle` 自己提取径向边缘；`FitCircle` 只消费点集。二者输入和算法不同，不能互相替代参数。

### 7.4 高度图平面与间隙

```text
GrabImage（32 位 TIFF） → 3DPreProcessing → FitPlane
                                           ↘ GapMeasure3D
```

1. 先用预处理统计确认 NoData 和高度范围。
2. 写入真实 `pixelSizeX/Y` 与 `zScale`。
3. 用基准平面核对法向、RMS 和平面度。
4. 在已知间隙的标准件上调平滑、导数阈值和峰间距。
5. 对无间隙、边缘缺失和全部无效高度样本验证 `gap_found=false`。

### 7.5 检测结果写 PLC

```text
采集 → 检测/测量 → DataCheck / Condition → PLCWrite
```

先使用 `PLC通信测试` 或 `PLCRead` 验证 IP、端口、从站号、地址和字节序，再启用写入。默认 Modbus TCP 示例地址为 `192.168.1.100:502`、从站号 1、超时 3000 ms，这些只是占位默认值，不能直接用于产线。

### 7.6 逻辑、循环与并行

- `If`：布尔链接格式为 `$模块实例.结果键`；表达式模式当前主要识别 true/false，不是通用表达式解释器。
- `Loop`：默认 1 次；先用小次数验证副作用。
- `While`：默认最大 1000 次；条件变量必须在循环中有明确更新路径。
- `StopWhile`：在满足条件时提前结束循环。
- `Parallel`：默认并发数 2，有效范围 2–10；只有元数据声明 `execution.threadSafe=true` 的模块才会真正并发，其他模块自动串行。
- `Delay`：默认 100 ms；会直接增加流程节拍。

## 8. SAM 快速标注与流程分割

### 8.1 快速标注

1. 先在图像视口加载目标图像，再点顶部“快速标注”。程序优先把当前有焦点的图像视口交给标注窗口；没有焦点图像视口时，使用第一个有图像的视口。若打开了多个视口，请先点击目标视口再启动。
2. 首次使用点“初始化环境”，再“导入权重”；环境与权重不会进入 C++ 工程或 Git。
3. 选择类别，使用“正点”“负点”或“框选”给出提示。
4. 多候选结果可用 `◀/▶` 切换；`Enter` 确认、`Esc` 取消当前预览、`Delete` 删除对象。
5. 已确认对象可执行膨胀、腐蚀、橡皮擦、合并和拆分，并可用 `Ctrl+Z` 撤销。
6. “保存会话”保留 `.deeplux-anno.json`；按训练工具需要导出 LabelMe、YOLO Seg 或 COCO。

Agent 可以引导用户完成这段 GUI 操作，但不能代替点击入口，也不能把 `sam_predict` 或 `sam_annotate` 的直接工具调用说成已经打开了标注窗口。快速标注入口目前只通过用户界面操作。

### 8.1.1 保存视口快照

在目标视口工具栏选择“保存快照”，然后在系统文件保存对话框中选择路径，并由用户处理已有文件的覆盖提示。Agent 可以说明操作步骤，但不会替用户选择任意路径或报告尚未由用户确认的保存结果。

真实 GPU 推理、权重兼容性、精度和吞吐量必须在目标环境验收。

### 8.2 流程模块 SamPredict

`SamPredict` 用于固定提示的流程内分割，默认参数：

- `serverUrl=http://127.0.0.1:8990`
- `label=object`
- `points=[]`
- `negativePoints=[]`
- `box=null`
- `timeoutMs=30000`，可调 100–120000 ms

正点 `points=[[x,y],...]` 与框 `box=[x,y,w,h]` 至少提供一种；负点用于排除区域。输出强类型 `Region2D`、得分和图像，可连接 `RegionStats` 计算面积、外接矩形和质心。服务不可达、超时或后端错误时模块失败关闭。

### 8.3 查询标注会话

Agent 可用只读工具 `get_annotation_session(sessionPath, offset?, limit?, includePolygon?)` 查询用户明确指定的 `.deeplux-anno.json`。结果按保存顺序分页，默认每页 20 项、最多 50 项；对象提供稳定 ID、标签、得分和提示点数量，bbox 与可选 polygon 使用该会话绑定图像的像素坐标。若会话图像来自 CropImage，坐标为该会话图像的 crop-local 坐标，不表示父图坐标。掩膜 RLE 不进入对话结果，响应最多 64 KiB；需要缩小结果时降低 `limit` 或关闭 polygon。

该查询最多读取 64 MiB 的会话文件，不启动 SAM、不解码图像，也不会在快速标注窗口中打开会话。若要编辑会话，仍在 GUI 中操作；Agent 返回查询结果不表示图像已加载、会话已打开或推理已运行。

在快速标注窗口打开且有已确认标注时，可让 Agent 使用需确认的 `save_active_annotation_session(outputPath)` 将当前完整内存会话保存为新的 `.deeplux-anno.json` 文件。`outputPath` 必须是绝对路径，父目录必须已存在，目标文件必须不存在；现有文件不会被覆盖。保存前确认卡会显示目标路径和对象数，并在确认时重新核对活动窗口、图像、会话和目标目录。此工具不会改写当前内存会话、GUI 撤销栈或原会话文件。

若要在快速标注窗口加载已有会话，可让 Agent 调用需确认的 `open_active_annotation_session(sessionPath)`。`sessionPath` 必须是绝对路径，指向原生 `.deeplux-anno.json` 普通文件。绑定图像必须可读，且其尺寸与像素摘要必须和会话记录一致；如果确认前会话、图像或当前窗口发生变化，操作会过期并要求重新发起。打开成功会替换窗口中的活动会话与绑定图像，并清空旧的未确认提示、预测预览和 Undo/Redo；源会话与图像文件不会被改写。SAM 后端使用应用生成的固定临时图像快照，切换或清空图像、关闭窗口时自动删除。没有绑定图像且没有标注的空会话可作为草稿打开，窗口保留当前画面作为背景。

### 8.4 导出标注会话

Agent 可用危险工具 `export_annotation_session(sessionPath, format, outputPath, categories?)` 将用户指定的会话导出为 LabelMe JSON、YOLO Seg 文本或 COCO JSON。工具会显示源会话、格式和新目标路径，并要求确认。目标必须是尚不存在的文件；工具不会覆盖文件或自动选择文件名。父目录须已存在。YOLO Seg 必须给出有序 `categories`，且包含会话内所有标签；类别顺序就是 class ID 顺序。LabelMe 不接受 categories；COCO 可选类别列表，未列标签按会话首次出现顺序追加。

### 8.5 修改或删除会话中的标注对象

Agent 可使用需确认的 `transform_annotation_session(sessionPath, outputPath, operation, objectIds, label?)` 基于指定会话创建一个新会话副本。`operation=set_label` 会将所选对象标签改为 `label`；`operation=delete_objects` 会从副本中删除所选对象。一次请求只执行一种操作，最多 100 个对象 ID。源会话保持不变，输出路径必须是尚不存在的 `.deeplux-anno.json` 文件。

该操作保留会话 JSON 中未修改的扩展字段及对象掩膜数据。它不会修改快速标注窗口的内存会话、GUI 类别列表或撤销栈，也不会自动打开生成的副本；需要继续在 GUI 中编辑时，用户应自行打开输出文件。

### 8.6 选择流程节点

GUI 打开时，Agent 可调用 `select_flow_module(instanceId)`，使用 `get_flow_state` 返回的实例 ID 同步选择流程树、画布和检查器，并显示检查器参数页。成功响应包含 `paramsTabVisible: true`。这是只读导航，不会修改节点参数或启动流程。检查器固定到其他节点时，工具返回 `INSPECTOR_PINNED` 并保持现有选择；无 GUI 窗口时返回 `REQUIRES_GUI`。

### 8.7 控制工作区面板

GUI 打开时，Agent 可调用 `set_workspace_panel_visibility(panel, visible)` 显示或隐藏 `tools`（工具）、`process`（流程）、`bottom`（底部）面板。该操作不要求打开工程，也不修改工程内容。无 GUI 时返回 `REQUIRES_GUI`。

成功响应分别给出 QAction 的期望状态 `visible` 和面板实际状态 `effectivelyVisible`。焦点模式会临时隐藏面板；此时若期望显示，响应会标记 `suppressedByFocusMode: true`。退出焦点模式后按期望状态恢复。工具调用不会直接写设置，但应用正常关闭时会沿用现有窗口布局保存逻辑。

### 8.8 筛选运行日志

GUI 打开时，Agent 可用 `set_log_level_filter(minimumLevel)` 设置运行日志表的最低显示级别：`all`、`debug`、`info`、`warning` 或 `error`。该工具只筛当前窗口的运行日志表，不清除日志，也不改变 Logger 的持久记录；无 GUI 时返回 `REQUIRES_GUI`。

`SUCCESS` 按 `Info` 级别参与筛选。当前表格已有行可以随阈值变化显示或隐藏；新日志若低于当时阈值，会被运行日志界面略过，不缓存为表格行，因此之后降低阈值不会补回它们。成功响应中的 `visibleRows` 是表格内未隐藏的行数，不受滚动位置影响。

### 8.9 将 Agent 对话滚动到最新消息

GUI 打开时，Agent 可调用 `scroll_agent_chat_to_latest()` 将当前对话滚动到最后一条消息，并恢复后续消息的自动跟随。工具不会发送消息、展开或切换面板，也不改变输入草稿、附件或已有对话；无 GUI 时返回 `REQUIRES_GUI`。

### 8.10 确认后清空运行日志

Agent 可调用危险工具 `clear_runtime_logs()` 请求清空日志。Advisor 和 Autopilot 都会显示确认卡，确认卡说明清理范围；Observer 拒绝。批准后清除 Logger 中所有类别的内存记录及连接的运行日志表，不删除磁盘日志文件，也不清除独立的 Agent 操作历史。成功响应中的条目数是执行清理时的快照数；聊天工具循环之后可能重新写入新的 AgentLoop 记录。人工点击运行日志面板中的清空按钮仍沿用原有的直接清空行为。

### 8.11 查看最近工程

Agent 可调用只读工具 `list_recent_projects()` 查看应用已有的最近工程路径、文件名和当前文件存在/类型状态。它不会扫描目录、读取工程内容或切换当前工程。要打开其中一个工程，仍需单独调用 `open_project`；该操作继续遵守自身权限门、未保存工程策略和候选工程验证，只有既有权限规则要求时才会确认。

### 8.12 设置界面主题

GUI 打开时，Agent 可调用 `set_theme(theme)` 将当前主窗口设为 `light` 或 `dark`。显式目标可重复设置；Advisor 会进入标准确认流程，Autopilot 可直接执行，Observer 拒绝。配置已初始化时，设置会写入 `appearance.darkTheme`；配置未初始化时只影响当前窗口。若保存失败，界面仍已切换，工具返回 `CONFIG_SAVE_FAILED` 并标明 `applied:true`、`persisted:false`。人工点击主题菜单仍按当前行为反转主题。

### 8.13 固定检查器

GUI 打开时，Agent 可调用 `set_inspector_pinned(pinned)` 显式固定或取消固定当前模块检查器。参数必须是 boolean；该设置只改变检查器跟随流程节点选择的行为，不要求工程或已选模块。Observer、Advisor、Autopilot 均可直接使用；人工点击检查器图钉仍执行原有切换操作。检查器状态仍按主窗口既有设置逻辑在关闭时保存。

Agent 还可分别用 `set_inspector_collapsed(collapsed)` 折叠/展开检查器，或用 `set_inspector_visibility(visible)` 关闭/重新打开检查器。两项均为无工程要求的界面状态操作，三种权限可直接执行。关闭会清空检查器显示内容，但保留固定状态和流程树/画布当前节点；重新打开后恢复当前节点的检查器内容。折叠不会关闭检查器。

### 8.14 调整主图像视口缩放

GUI 打开且主视口当前显示 2D 图像时，Agent 可调用 `set_primary_viewport_zoom(action)`，`action` 支持 `zoom_in`、`zoom_out`、`fit`、`actual`，分别表示放大、缩小、适应窗口和 1:1。Observer、Advisor、Autopilot 均可直接使用，不需要工程。操作只作用于主视口；没有当前 2D 图像时返回 `NO_IMAGE`，包括当前处于 3D 模式但仍缓存有图像的双数据视口。专用数据源视口、3D 点大小、平移、ROI 和测量标注不受此工具控制。

### 8.15 调整主 3D 点云点大小

GUI 打开且主视口当前显示 3D 点云时，Agent 可调用 `set_primary_viewport_point_size(size)`，范围为 1.0–8.0、最多一位小数，例如 3.7。`0.5` 是人工 SpinBox 的步进值，不限制 Agent 的显式设置。Observer、Advisor、Autopilot 均可直接使用，不需要工程。成功响应与主视口点大小控件及 renderer 一致；非 3D 视图返回 `NO_POINT_CLOUD_VIEW`。操作只改变主视口的显示大小，不改变点坐标、点云数据或专用视口。

### 8.16 切换主视口 2D/3D 模式

当同一主视口同时缓存非空图像和点云时，Agent 可调用 `set_primary_viewport_display_mode(mode)` 显式设置 `2d` 或 `3d`。实际切换会恢复对应缓存内容；切换到 2D 时会通知界面刷新图像。重复设置当前模式时，如果当前内容有效，返回 `changed:false`，不重复刷新。图像或点云缓存缺失/无效时分别返回 `NO_IMAGE` 或 `NO_POINT_CLOUD`。操作只影响主视口，不加载文件、不修改工程数据或专用视口。

### 8.17 设置 3D 点云渲染模式

GUI 打开且主视图有可见点云时，Agent 可调用 `set_point_cloud_render_mode(mode)`，选择 `uniform`（统一色）、`rgb`、`height`（高度）、`intensity`（强度）、`normal`（法向）或 `blinn_phong`。可用模式沿用“视图”菜单根据当前点云字段显示的选项；不可用时返回 `RENDER_MODE_UNAVAILABLE`，不会更改当前模式。无可见点云时返回 `NO_POINT_CLOUD_VIEW`。

Agent 可调用 `close_viewport(viewportId)` 关闭视图状态中的一个明确视口。主视口或唯一视口会清空内容并保留；附加视口会销毁。关闭专用数据源视口只移除窗口内的视口映射，不删除工程数据源或文件。

该操作复用“视图”菜单中的同一项选择，并将目标模式应用到主窗口管理的所有数据视口。当前处于 2D 的双数据视口会记住目标 3D 模式，之后切换到 3D 时应用。工具只改变渲染显示，不修改点云数据或工程；Observer、Advisor、Autopilot 均可直接使用。

### 8.18 快速测量的人机采点

快速测量必须由用户在 GUI 视口中手动点击或拖拽；Agent 只能创建请求、说明采点步骤、查询进度或取消，不能代替用户输入坐标。

1. Agent 先调用 `list_viewports()`，根据返回的 `viewportId`、`mode`、`hasImage` 和 `hasPointCloud` 与用户确认目标视口。该查询无需打开工程。
2. 调用 `begin_quick_measurement({viewportId, dimension, measurementType})`。`dimension` 为 `2d` 或 `3d`；类型为 `distance_2_points`、`point_to_line`、`segment_gap`、`angle_3_points`、`circle_3_points` 或 `rectangle_area`。目标必须正显示兼容内容：2D 是 Auto2D 图像，坐标为图像像素；3D 是 Auto3D 点云，坐标为点云原生世界坐标，工具不推断物理单位。矩形面积只支持 2D，3D 请求会拒绝。
3. 工具返回唯一 `requestId`、当前状态、采点步骤和 `nextStep`。按提示在指定视口手动点击；矩形面积按提示拖拽一次 ROI。其他视口的点击不会计入请求。
4. 用户完成后，Agent 用 `get_quick_measurement_status({requestId})` 查询 `completed`；等待时可继续查询，或用 `cancel_quick_measurement({requestId})` 取消。`completed`、`cancelled` 和 `expired` 都是终态。关闭或清空目标视口、替换显示内容、切换模式、切换工程或关闭窗口会使等待请求过期。

测量数值只显示在现有视口覆盖和运行日志中；状态工具只报告步骤状态，不返回数值。若要读取数值，用户应直接检查 GUI 显示。Observer 只能列举视口和查询状态；Advisor 开始/取消请求须确认；Autopilot 可直接开始/取消，但仍需要用户手动采点。GUI 自身的快速测量与 Agent 等待请求互斥。

会话和生成文件各有 64 MiB 上限。导出使用原子 no-replace 发布：如果其他进程先创建目标，操作失败并保留该文件。LabelMe 与 YOLO Seg 导出 polygon；COCO 采用 exporter 既有 polygon/bbox/area 规则。工具只写导出文件，不复制图像、不改会话或工程，不表示 GUI 已加载导出结果。

### 8.19 编辑活动 SAM 会话掩膜

打开快速标注窗口并加载图像、确认至少一个标注对象后，可让 Agent 查询对象摘要并编辑掩膜。查询只返回对象 ID、标签和会话中保存的 bbox，不返回原图、提示坐标、多边形、RLE 或本地路径。对象较多时可用 `offset` / `limit` 分页；每页最多 50 项、响应最多 64 KiB。

`edit_active_annotation_masks` 支持一次执行一种操作：`dilate`（膨胀）、`erode`（腐蚀）、`erase_stroke`（擦除）、`merge`（合并两个对象）和 `split`（按连通分量拆分）。坐标及 `radiusPx`（1–32）均使用当前活动标注图像的像素单位；活动图像来自 CropImage 时，笔画点为 crop-local 坐标，不会自动转换到父图。对象 ID 应先从 `list_active_annotation_objects` 取得；擦除笔画用 `strokePoints: [[x,y], ...]`，最多 4096 点。合并要求两个对象掩膜的并集是一个连通分量；拆分沿用既有最多 64 个分量及 256 MiB 物化预算限制。

### 8.20 管理活动 SAM 类别和对象标签

`list_active_annotation_categories` 列出当前可见标注窗口的临时类别以及分页对象 ID/标签。它不返回掩膜、提示坐标或图像。`edit_active_annotation_categories` 支持 `add_category`、`remove_category` 和 `set_object_label`，每次只执行一种操作，且须由用户逐项确认。新增/移除只改变当前对话框临时类别列表，不自动保存；删除类别不会改动已有对象标签。给对象改标签时，目标必须是现有类别；一次最多选择 64 个对象，更新通过 GUI 撤销栈，可在窗口中撤销/重做。对象和类别变更只在内存中生效，需用户另行保存会话。

所有编辑都需要用户确认，即使使用 Autopilot。确认卡显示操作、对象 ID、半径与笔画点数，不显示笔画坐标；确认前如窗口、图像或会话内容变化，操作会过期并要求重新发起。批准后编辑进入快速标注窗口现有的撤销/重做栈。修改只存在于活动窗口的内存会话，不自动保存、不更改工程或源图像；需要保留时，用户仍应在快速标注窗口中手动保存会话。Observer 可以查询对象摘要，但不能执行编辑。

### 8.21 查询并取消活动 SAM 提示

`get_active_annotation_prompt_status` 只返回当前可见快速标注窗口是否有点/框提示、SAM 预测是否在途以及候选数量；不会返回提示坐标、掩膜、图像或路径。`cancel_active_annotation_prompt` 取消这些临时提示状态和当前预测请求。Advisor 与 Autopilot 都需要逐项确认；Observer 只能查询。

取消不会删除已确认对象或清空 GUI Undo/Redo。取消前创建的提示编辑命令会失效，不能通过撤销/重做恢复旧提示；之后新建的提示和标注对象仍按原有撤销栈行为工作。迟到的 SAM 响应不会恢复已取消的预览。取消只影响当前可见对话框中的临时状态，不保存会话文件，也不改变图像、工程、类别或已确认标注。

### 8.22 打开系统设置

GUI 打开时，Agent 可调用 `open_system_settings()` 请求显示系统设置窗口。调用只负责打开或激活现有窗口，不读取或修改配置；用户需自行查看控件并决定是否保存或重置。成功仅表示显示请求已发出，不表示窗口已置于前台，也不表示设置已保存。无 GUI 时返回 `REQUIRES_GUI`。

## 9. Agent 对话与软件知识库

### 9.1 配置 Agent

打开“工具 → Agent 设置”，填写 Endpoint、API Key、模型、Temperature 和 Max Tokens，并选择权限级别：

- Observer：只读查询。
- Advisor：写操作前确认，适合日常使用。
- Autopilot：普通写操作可自动执行，保存工程、写标注文件等危险操作仍需确认；应只在受控工程中使用。

Agent 只调用白名单内部工具，不具备任意 shell 权限。流程运行期间不能通过 Agent 修改工程；`run_flow` 为异步调用，应等待完成后读取结果。

### 9.2 查询内置手册

本手册和插件手册已作为内置只读知识文档随软件打包。可在 Agent 对话中直接问：

- “如何创建 GrabImage 到 FindCircle 的找圆流程？”
- “MeasureCircle 的 threshold 和 searchLength 怎么调？”
- “GapMeasure3D 未检出时应该检查哪些结果？”
- “列出 PLCWrite 上线前检查项。”

Agent 会通过 `read_documentation(topic)` 按标题和正文关键词检索，并在答案上下文中保留来源文件名。询问精确实例参数时，它还应先读取当前模块参数 Schema。

### 9.3 添加现场文档

打开“工具 → Agent 设置 → 知识库...”可查看内置文档，或添加 `.md`、`.markdown`、`.txt` 文件。添加动作会把文档复制到用户知识库目录；移除用户文档不会删除原文件，内置文档不可移除。

建议现场文档使用清晰的 `##` / `###` 标题，并包含设备名、产品型号、工位、参数名和故障码等检索关键词。不要加入 API Key、密码或未经脱敏的客户数据。

### 9.4 通过 Agent 登记数据源

在已有工程中，可以让 Agent 执行“导入/登记这个本地图像或点云文件”。`import_data_source` 需要对每个文件逐项确认；Observer 权限不能执行。支持 PNG/JPG/JPEG/BMP 图像、PLY 点云和 TIFF 高度图。批准后软件会验证文件并把规范路径登记到当前工程。

Agent 登记引用不会打开或切换主视口、不会配置 `GrabImage`，也不会复制、移动或修改源文件。需要查看数据时，再让 Agent 单独执行显示操作，或在“数据源”页选择相应文件。PLY 必须能按头部声明完整解析，截断或损坏的数据不会登记。

若要让流程下一次运行时读取该图像，请告诉 Agent 单独配置目标 `GrabImage` 实例：`grabSource` 设为 `File`，`filePath` 设为登记结果中的路径。此参数修改需要确认；数据源登记和流程参数修改是两个独立步骤。

### 9.5 在专用视口显示数据源

在 GUI 打开且工程已登记数据源时，Agent 可执行 `display_data_source_in_dedicated_viewport(dataSourceId)`。Advisor 和 Autopilot 按危险操作确认规则执行，Observer 不允许。工具会加载或复用缓存，并在该数据源专用视口显示；重复调用复用同一视口。冷加载不会改变主视口。隐藏的数据源需先单独设为可见；损坏或不支持的文件会返回加载失败，不会报告成功。

显示操作不修改工程引用、源文件或 `GrabImage` 参数。它与 `display_data_source` 的主视口显示操作相互独立。

需要复制数据源路径时，可让 Agent 执行 `copy_data_source_path_to_clipboard(dataSourceId)`。该操作会替换系统剪贴板，必须在确认卡中核对数据源和完整路径后批准；它不修改工程或源文件。空路径和重复 ID 会被拒绝。

### 9.6 管理全局变量

Agent 可通过 `list_global_variables`、`get_global_variable`、`create_global_variable`、`set_global_variable` 和 `remove_global_variable` 查询并维护全局变量。工具严格保留支持的 JSON 标量/数组类型；修改遵循各自权限确认与流程运行期锁。全局变量属于应用进程状态，不随工程保存或重开。Agent 工具不打开 GlobalVarView 窗口，也不提供表格排序、表达式执行或手动“应用”操作；它们不能用字面值 set 代替表达式运算。

## 10. 常见故障排查

| 现象 | 优先检查 |
| --- | --- |
| 左侧没有插件 | 是否执行 `sync-plugins`；用户插件目录是否可写；启动画面是否报告加载失败 |
| 流程不能运行 | 是否有工程和模块；必需端口是否连接；参数校验和运行日志是否报错 |
| 参数改了但结果没变 | 节点是否显示待运行；是否重新运行；查看的是不是旧节点输出 |
| 节点运行失败 | 检查器“结果”页错误、运行日志、输入数据类型和上游连接 |
| 图像为空 | `GrabImage.grabSource`、路径/相机 ID、格式、权限和超时 |
| 找圆不稳定 | 缩小半径范围；固定光照；检查预处理；再调 `param1/param2` |
| Blob 数量异常 | 先看二值图；检查阈值模式、面积范围、圆度和目标粘连 |
| 点集拟合失败 | 点数是否足够；是否有重复、共线、NaN/Inf；RANSAC 阈值是否过小 |
| 3D 结果极大或全零 | NoData、填充值、像素尺寸、Z 比例、通道和高度单位 |
| GapMeasure3D 输出 -1 | 先看 `gap_found`；检查 ROI、无效值、导数阈值、边缘剔除和峰间距 |
| PLC/TCP/串口失败 | 地址、端口、从站、寄存器、波特率、字节序、防火墙和超时 |
| SAM 无法预测 | 是否初始化环境、导入权重、启动服务；URL、GPU、显存和超时 |
| Agent 不回答软件问题 | Agent 连接是否成功、工具调用是否开启；知识库是否列出本手册；换用明确模块名作为关键词 |

排错顺序应保持为：输入 → 连线 → 参数 → 单节点结果 → 日志 → 外部设备。不要在多个环节同时改参数。

## 11. 上线验收清单

### 11.1 算法验收

- 正常、边界、缺陷和空输入样本均已覆盖。
- 参数、ROI、相机曝光和光源设置已记录。
- 与量具或人工标注完成精度、重复性、漏检和误检对比。
- 2D/3D 坐标和物理单位已标定；无效值处理有明确契约。
- 单次最大耗时和循环节拍满足要求。

### 11.2 系统验收

- 工程已保存并能重新打开，插件版本与工程一致。
- 相机断开、文件缺失、PLC 超时、网络中断和磁盘不可写时能够失败并留日志。
- 停止、断点、禁用节点和异常恢复均已演练。
- 输出文件名、目录、编码、覆盖/追加策略和磁盘空间符合现场规范。
- PLC 写入地址和合格/不合格映射经双方确认。
- Agent 权限符合现场策略，API Key 和知识库资料已脱敏。
